# Priyanshu Rai Portfolio

A complete responsive portfolio built as a simple static website.

## Run locally
Open `index.html` in a browser.

## Customize
- Replace the `PR` profile placeholder in `index.html` with your actual profile image.
- Update social URLs if you have the exact LinkedIn/Instagram profile URLs.
- Connect the contact form to Formspree, EmailJS, a backend, or another form service when ready.

## Deploy for free
This static site can be deployed on GitHub Pages, Netlify, Vercel, or Cloudflare Pages.
